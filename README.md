# car-# 🚗 YOLO Vehicle Counter

A real-time vehicle detection and counting system built using **YOLOv8, OpenCV, and CVZone**.

The project detects vehicles in a video, draws bounding boxes around them, and counts vehicles as they cross a predefined counting line.

---

## 📌 Project Overview

This project uses the **YOLOv8 object detection model** to identify vehicles in a video.

The detected vehicles are tracked across frames and counted when they cross a specific line in the video.

The system can be used for applications such as:

- 🚦 Traffic monitoring
- 🚗 Vehicle counting
- 🛣️ Road analysis
- 📊 Traffic flow estimation
- 🏙️ Smart-city surveillance

---

## ✨ Features

- Real-time vehicle detection
- YOLOv8-based object detection
- Vehicle counting using a virtual line
- Bounding boxes around detected vehicles
- Confidence score display
- Class labels for detected objects
- Video input support
- Processed video output support
- GPU acceleration using NVIDIA CUDA
- OpenCV-based video processing
- CVZone for improved visualization
